SMART INTERVIEW COACH
RECOMMENDED FEATURES
=====================

This file contains the recommended product features and implementation plan
for Smart Interview Coach.


1. CORE INTERVIEW FEATURES
--------------------------

- Dedicated interview room page.
- Live interview question display.
- Countdown timer.
- Start, pause, resume, and end interview controls.
- Voice recording.
- Speech-to-text transcript.
- Repeat question button.
- Skip question button.
- Submit answer button.
- Interview progress indicator.
- Question counter.
- Dynamic follow-up questions.
- Technical, behavioral, HR, managerial, and system design interview modes.
- Rapid-fire interview mode.
- Mock phone-screen mode.


2. REGISTRATION AND PERSONALIZED ONBOARDING
-------------------------------------------

- Collect full name, email, password, and confirmation password.
- Allow the user to upload a resume.
- Support PDF, DOC, DOCX, and TXT resume formats.
- Validate resume size before upload.
- Allow users without a resume to enter their details manually.
- Manual profile fields:
  - Target role.
  - Experience level.
  - Skills and technologies.
  - Career goals.
- Ask for user consent before analyzing profile information.
- Extract resume text securely on the backend.
- Use AI to analyze:
  - Candidate name.
  - Current role.
  - Previous roles.
  - Years of experience.
  - Technical skills.
  - Soft skills.
  - Projects.
  - Education.
  - Certifications.
  - Recommended job roles.
  - Skill gaps.
  - Suggested interview difficulty.
- Generate an AI profile summary.
- Generate personalized interview topics.
- Generate recommended preparation steps.
- Store profile analysis status:
  - pending-ai-analysis
  - processing
  - completed
  - failed
- Never expose AI API keys in frontend code.
- Process resumes on the backend.
- Delete uploaded resume data when the user requests deletion.


3. AUTHENTICATION AND ACCOUNT SECURITY
--------------------------------------

- Backend registration.

- Logout and token removal.

19. SECURITY REQUIREMENTS
-------------------------

- Keep Gemini and database credentials in backend environment variables.
- Never store raw passwords.
- Validate all uploaded files.
- Limit resume file size.
- Validate MIME type and extension.
- Scan uploaded files before processing.
- Sanitize extracted resume text.
- Rate-limit authentication and AI endpoints.
- Authorize every user-owned resource.
- Avoid exposing private resume data in public links.
- Use secure cookies or short-lived access tokens.
- Log security events without logging sensitive resume content.
- Provide account and data deletion controls.
